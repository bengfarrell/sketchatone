## What you'll need

You need a supported drawing tablet, a computer running Sketchatone, and a MIDI sound source. A laptop or desktop is a natural place to start. Sketchatone doesn't need a particularly powerful computer; a Raspberry Pi 4 can run it too.

Tablet support is still being explored. Ben has tried the XP-Pen Deco 640 and Huion Inspiroy 2 Medium, but not every tablet has been tested. Read the [project notes and tablet experience](/about/) before buying hardware, then use the [setup guide](/about/getting-started/) to get connected.

## Play beside a MIDI keyboard

Lay the tablet beside a MIDI keyboard. Use one hand to set the chord and the other to strum. You can keep both on your desk without needing to build anything.

Prefer buttons? A small USB numeric keypad or the tablet's own buttons can take care of chord changes. See the [different ways to choose chords](/playing/chords/).

## Build something you can wear

With a Raspberry Pi, you can fit the computer and tablet on a frame small enough to wear. Add a strap and you can play it like a guitar.

There's no ready-made hardware kit, so this part is DIY. Think about a secure mount, comfortable reach, power, and where the MIDI cable will go. Get everything working on a desk first, then build around that setup.

The [Raspberry Pi installation guide](/about/builds/) covers the software. If you want the Pi to appear as a MIDI controller over USB, see the [USB MIDI guide](/about/usb-midi-gadget/).

## Other layouts work too

You don't have to use a guitar-shaped frame. A MIDI keyboard, a regular keyboard, or a small keypad can handle chord changes. Try a few positions for the tablet and buttons before you commit to a build.
